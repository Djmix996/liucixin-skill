# liucixin-skill

纯提示词版「刘慈欣硬科幻写作」Skill。

- **无 references 子目录**
- **无脚本、无 hook**
- 只有一个 `SKILL.md`，可被严格要求「纯提示词型」的安装器直接安装

## 安装

直接把本仓库地址填进你的 Skill 安装器：

```
https://github.com/Djmix996/liucixin-skill
```

或只装 SKILL.md：

```
https://github.com/Djmix996/liucixin-skill/blob/main/SKILL.md
```
